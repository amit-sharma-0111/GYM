# 🏋️ FitZone – Premium Gym Website

A modern, fully responsive gym website built with **HTML, CSS, and JavaScript**.

🔗 **Live Demo:** [fitz0ne-gym.netlify.app](https://fitz0ne-gym.netlify.app)

---

## ✨ Features

- 🌙 **Dark / Light Theme** toggle with localStorage persistence
- 📧 **Working Contact Form** – real emails via Formspree
- 🧮 **Interactive BMI Calculator** – Metric & Imperial support with animated scale
- 💳 **Pricing / Membership Plans** – 3 tier cards (Basic, Pro, Elite)
- 🎬 **Hero Video Background** with smooth parallax effect
- 🖼️ **Gallery Lightbox** – click to expand images
- 💬 **Testimonials Filter** – filter by category
- 🎥 **Workout Video Section** with modal popup player
- ✨ **AOS Scroll Animations** – fade/slide on scroll
- 📱 **Fully Responsive** – mobile, tablet, desktop
- 🔝 **Back to Top** button
- 🔗 **Active Nav Highlight** on scroll
- ⚡ **Form Validation** with real-time feedback

---

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Structure & Semantic markup |
| CSS3 | Styling, Flexbox, Grid, CSS Variables |
| JavaScript (ES6+) | Interactivity & Logic |
| AOS.js | Scroll animations |
| Formspree | Contact form email service |
| Netlify | Hosting & Deployment |
